Day-wise curriculum

Explore the topics and hands-on lab for each day.

DAY 01RAG Systems: Embeddings, Vector Databases & Retrieval5 focused topics · Applied lab⌄
  1. RAG architecture: ingestion, indexing, retrieval, generation and grounding
  2. Document parsing, chunking, embedding models and similarity measures
  3. Vector databases, indexing, metadata filters and semantic search
  4. Dense versus sparse retrieval, hybrid search, reranking and query expansion
  5. Retrieval quality, citation grounding and common RAG failure modes
⌘   HANDS-ON LAB

Build a document-to-vector pipeline and evaluated RAG question-answering assistant

DAY 02Agentic AI: Agents, Tools & Orchestration5 focused topics · Applied lab⌄
  1. Agentic systems versus deterministic AI workflows; decision boundaries
  2. Tool/function calling, schemas, structured responses and execution controls
  3. Planning, ReAct-style patterns, stateful workflow graphs and routing
  4. Single-agent versus multi-agent orchestration and supervisor patterns
  5. Checkpoints, retries, exception handling, approvals and agent guardrails
⌘   HANDS-ON LAB

Implement a tool-enabled RAG agent with an approval-aware workflow

DAY 03Context Engineering, Memory Design & MCP5 focused topics · Applied lab⌄
  1. Context lifecycle: acquisition, selection, assembly, compression and expiry
  2. Token budgets, context relevance and session-state management
  3. Working, episodic/session and long-term memory; retention and isolation
  4. MCP hosts, clients, servers, tools, resources and protocol interactions
  5. Implement an MCP tool server; connect enterprise APIs and data securely
⌘   HANDS-ON LAB

Connect an MCP server to an agent and add session-aware memory

DAY 04AI System Design, APIs & Model Strategy5 focused topics · Applied lab⌄
  1. Enterprise reference architecture: RAG, agents, services and data planes
  2. FastAPI endpoints, asynchronous jobs, streaming, gateways and caching
  3. Authentication, authorization, resilience, latency and scaling choices
  4. Prompting, few-shot patterns, RAG and fine-tuning: when to use each
  5. Fine-tuning overview: SFT, LoRA/PEFT, data requirements and trade-offs
⌘   HANDS-ON LAB

Expose the assistant as an API; compare prompting and retrieval-enhanced responses

DAY 05AI Observability, Evaluation & In-Database Predictive Analytics5 focused topics · Applied lab⌄
  1. AI tracing: prompts, tool calls, retrieval steps, tokens, latency and cost
  2. RAG and agent evaluation: faithfulness, relevance, task success and safety
  3. Automated evaluation suites, monitoring dashboards and regression tests
  4. SQL-based feature engineering, scoring and database-native ML concepts
  5. Prediction use cases, platform capabilities, batch/in-database scoring and agent integration
⌘   HANDS-ON LAB

Instrument an AI workflow and integrate SQL-driven inventory demand predictions

DAY 06Integrated Enterprise AI Engineering Capstone5 focused topics · Applied lab⌄
  1. Integrate embeddings, vector storage, retrieval and grounded answers
  2. Add an orchestrated, tool-using agent and MCP-based data access
  3. Apply context management, memory, APIs and approval controls
  4. Expose predictive analytics from a database to support decisions
  5. Run evaluation, inspect traces, present architecture and demonstrate outcomes
⌘   HANDS-ON LAB

Build and demonstrate an Inventory Intelligence & Decision Support Assistant
